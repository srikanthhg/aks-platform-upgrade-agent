# Package manifest

This archive contains one GitHub-style repository with:

- React/TypeScript frontend under `frontend/`
- FastAPI, LangGraph agents, and worker under `backend/`
- PostgreSQL durable state, queue, locks, audit, and reports
- Backend and frontend Dockerfiles
- Local Docker Compose stack
- Backend automated tests
- GitHub Actions for tests, compilation, repository validation, and Docker builds
- Azure Container Apps Bicep
- Entra ID and Key Vault-oriented production configuration
- Architecture, local development, deployment, operations, validation, security, and contribution documentation

Real AKS upgrades are disabled by default.
